# 小开二维随行形象

`xiaokai-poses.webp` 是用户于 2026-09-29 确认的二维校园精灵形象的网页状态图集，使用内置图像生成工具依据确认稿制作，再经一次仅调整分格留白的生成修订。没有引入角色引擎、实时三维模型或视频依赖。

## 消费契约

- 尺寸：1536 × 1024；3 列 × 2 行；每格 512 × 512；RGBA 透明背景。
- 顺序：第一行 `idle`（待机）、`listening`（倾听）、`thinking`（思考）；第二行 `speaking`（说话）、`acting`（指引）、`error`（温和提醒）。
- 每格为完整角色姿态，网页按实际交互状态切换。它们不是连续动画帧，不应按帧率循环假装连续说话或口型同步。
- 角色主体不跨分格；以 alpha > 32 检查，各格主体横向范围依次为 107–453、101–421、90–411、114–447、86–432、87–420 像素。上下两行主体在各自分格中的脚尖高度约为 483 与 448 像素；若需更严格的视觉基线，可在显示层对第一行向上偏移约 35/512 格高。
- 留白用于保护翅膀、长发和地图；布局应按整格计算点击范围。生成的极低 alpha 抗锯齿边缘保留，无程序抠图、阈值裁边或二次绘制。
- 正式文件为 WebP quality 90 / method 6，未改变尺寸，alpha 与生成 PNG 逐字节相同。文件 298,724 字节（约 292 KiB）。
