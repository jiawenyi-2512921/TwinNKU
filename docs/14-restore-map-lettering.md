# 恢复原规划图文字显示

2026-09-23，用户反馈新增地图名称层效果更差，要求换回文字直接写在图上的版本，并保留周恩来雕像。

## 当前效果

- 底图继续显示原来已写在规划图上的名称，8279×5604原尺寸及265张PNG瓦片未改变。
- 删除常驻白底浮动名称、固定14px字号、自动避让与名称开关；不再给原图中的文字叠第二套标签，也不恢复数字序号。
- 周恩来雕像在综合业务西楼和东楼正中央，沿用已确认坐标和独立点位ID。新名称采用普通文字和浅色描边，颜色与原文化点位相近；以图像像素坐标显示，随底图平移、缩放。没有白色卡片、阴影或额外定位图钉。
- 保留83个命名地点的建筑轮廓点击、高亮、悬停提示、键盘访问、搜索与分享。未命名建筑仍不可点击。
- 楼层仍只展示有标注图，已接入图书馆1层；其他材料状态不变。

雕像文字是贴合图像坐标的SVG补充，未重编码底图；原有建筑文字仍来自原PNG。两个文字来源均跟随地图缩放。固定在屏幕上的白底名称层已删除。雕像标注不拦截拖动与下方区域点击。

## 给DeepSeek的更新步骤

这次是前端显示修正，地图仍是revision 3，楼层仍是revision 2，无新增数据库迁移或资源包。

1. 备份并保留服务器当前配置与数据卷，获取仓库`jiawenyi-2512921/TwinNKU`的`feat/floor-viewer-m05`分支最新代码（PR #3）。不要使用资源Release里的旧Source code压缩包。
2. 在项目根目录执行`bash scripts/deploy.sh`重建运行镜像，然后执行`python3 scripts/smoke.py https://2512921.cn`。
3. 若地图v3和图书馆有标注楼层v2已经导入，不重复导入、不清理卷。尚未导入时，按[资源交付说明](13-map-interaction-update.md)下载并导入原资源即可。
4. 浏览器重新加载页面，确认已加载新版本的前端静态文件。

资源继续从[地图v3发布页](https://github.com/jiawenyi-2512921/TwinNKU/releases/tag/map-interactions-2026.09.23-v3)获取。该页面的资源附件有效，其标签绑定的源码保留了旧浮动名称，所以代码必须使用PR #3最新提交。
