## 问题与改动

- 两个公开资源面板原本各自监听 30 秒轮询、窗口焦点及可见性；没有接收联网恢复和同源发布广播。现复用既有 `watchCatalogChanges`，恢复网络、回到页面或收到发布通知时重新读取公开 API；隐藏页延后到可见时读取。
- 通知仅触发读接口，不携带或采信业务数据。发布期间正在进行的旧读取会被取消，迟到结果不得覆盖最新资料；离开面板时释放监听器、轮询和广播通道。
- 相同 VR 列表保留对象身份，避免分享卡片在每轮轮询后重复触发滚动。楼层继续保留当前层/分区/展开状态；浏览器历史恢复仍独立解释 URL。
- 公开列表的改名、图片 URL/版本更新和撤回继续由实际 API 响应决定。本次不改数据、地图坐标、图片字节、契约、权限或写入流程。
