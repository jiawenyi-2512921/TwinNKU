## 显示方式与原图保护

- 不修改底图文件、瓦片、地图版本、已校准点位轮廓、入口或路网。
- 两处大号旧名称是此前写入瓦片的附加文字。当前部署地图与用户原规划图的道路、树木等背景像素逐像素一致；恢复小片只提取原图背景，未重绘、生成、修补道路。
- `apps/web/public/assets/map-labels/` 内两个 PNG 为用户原图的原尺寸像素摘取，合计约146 KB。源图仍保持原字节。manifest 记录源图、当前地图及两个输出文件的 SHA-256。
- 只在地图 UUID、revision 3、8279×5604、source_sha256 全部匹配时绘制恢复层。换底图、换版本或指纹不符即停用，避免补丁错位。
- 新文字读取当前公开点位的锚点，不把本次线上坐标写死。西南门按狭长轮廓纵向排列，沿轮廓倾斜，位于团队已标注的入口范围内。学院名缩放后置于当前建筑锚点。文字及恢复片随地图一起移动、缩放，不拦截点击。
- 学院前台显示转换只接受指定 UUID 及两个明确旧名称；后续后台改成其他名称时保留新名称。原 API 数据、审核记录并未被此显示层改写。

