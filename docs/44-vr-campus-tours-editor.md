# VR 原网站入口、校园导览路线与编辑流程精简

> **最新更正（2026-09-29）：用户实测站内 VR 无法打开，要求改为原网站新标签页。以下全景说明取代此前“站内 iframe 播放”的方案；校园路线与编辑流程简化继续有效。**

本文同时保留上一批校区级路线及后台简化的交付说明。上一批从 `feat/admin-console` 的 `d65ec5c` 接续，新增0008迁移；本次 VR 入口修正只改 web，不增加 API 或数据库迁移。最终提交、测试与 CI 以根目录 `VALIDATION.md` 为准；没有将代码或自动测试说成学校网站真实播放已通过。

## 当前全景入口

- 地点的全景入口使用已发布资料的安全 HTTPS 原网址，点击后在新标签页打开；不先打开地点详情，也不再加载站内 iframe。链接使用 `target="_blank"` 与 `rel="noopener noreferrer"`，保留已发布场景参数和片段。
- 小开的 `open_vr` 动作先经过服务端动作核验和当前公开全景目录核对，再提供明确的原网站入口。访客点击后才打开新标签页；语音回答或异步动作完成不会自动弹出外部网页，也不直接执行模型给出的任意地址。
- 以前分享的 `?point=…&panorama=…` 链接仍可识别。本站重新读取公开资料后显示原网站入口；资料下架、读取失败或目标不匹配时给出说明，不保留失效播放器。
- Twin NKU 原标签页保留地图、导航、校园路线站点和小开对话。返回原标签页可继续使用；直接分享链接中的全景入口可以在本站关闭，不会要求浏览器后退到未知网站。

### 新标签页的边界

官方全景在其自己的网页运行，Twin NKU 的小开悬浮窗和麦克风不能跨页面出现在学校网站上。浏览器切到后台时可能暂停原页面语音；回到 Twin NKU 后，可点击麦克风继续。保留会话不等于语音可在第三方页面持续收听。

全景原网站的访问校验、触控旋转、场景切换和全屏由其自身提供，需在目标设备实际检查。本版本不再通过 iframe 的 `load` 事件判断播放成功，不重试站内嵌入、不绕过学校校验，也不代理或转存登录凭据。web 镜像包含对应 nginx/CSP 更新，普通页面不再需要为官方全景放宽 `frame-src`；原学校 SDK 页的独立规则继续保留。

## 定制的是校园导览路线

“校园导览路线”成为独立后台入口。创建时先选校区，再从该校区的授权地点选择多个站点；路线不再绑定一个无关的“主建筑”。可以串联校门、建筑、自然景观和文化点位，首站可以调整。

编辑顺序：

1. 选择路线所属校区，填写名称、整体介绍及资料来源。
2. 搜索地点名称或别名，把需要的地点加入站点清单。
3. 调整上下顺序；每次展开一个站点，编辑讲解及视频安排。更换站点后重新选择适用的媒体。
4. 检查清单后保存草稿，或点击“保存并提交审核”。另一位审核者确认后才对外发布。

每站仍使用现有字段：地点、讲解、同地点已发布视频，以及“打开本站时 / 读完介绍后 / 主动选择时”三种观看邀请时机。邀请不自动播放视频。最多 50 站，所有站点必须属于同一校区并位于操作员授权范围内；视频引用也必须匹配地点和公开状态。

“保存并提交审核”依次完成保存和提交，提交使用刚保存返回的版本号。提交失败时已保存草稿保留，并明确提示；不自动重试写请求、不越过独立审核直接发布。

公开端显示路线所属校区、真实站点名称、数量和顺序。开始、切站、跳过、完成、暂停及刷新恢复沿用本浏览器进度记录。逐站展示表达参观顺序；步行导航仍调用已审核路网，不能把站点连线当作道路，也没有增加 GPS 到达判断或室内导航。

## 日常编辑减步骤

后台按内容编辑、审核协作、设置记录组织入口。“视频与打卡”和“校园导览路线”分开；其他类型的待审核摘要折叠显示，进入审核中心时先看到当前任务。

地图点位仍使用已校准地图和轮廓。常用编辑以“选择地点 → 修改 → 保存并提交审核”为主，细坐标等精修项按需展开；审核账号继续核对修改前后差异，参与修改的人不能自审。

资料中心显式选择或新建资料后定位到编辑区；可返回列表继续处理，保留筛选条件。读取刷新不会反复抢走键盘焦点；离开未保存内容、上传中或写请求处理中的保护保持有效。

道路工作台优先显示选择/拖动、添加节点、连续绘制、检查连通和保存；弧线、自由描线、拆路、吸附/名称选项及导入导出放入“更多绘图与备份”。选择高级模式后，折叠栏仍显示当前模式。绘制中的完成/取消按钮只在有未完成形状时显示，形状尚未完成时不能保存或试算该片段。道路几何、候选初稿、发布核验和独立审核规则不变。

## 接口与数据库兼容（上一批校园路线升级）

- `ExperienceTourContent` 使用 `kind: "tour"`、`campus_id`、标题、整体介绍、来源和 `stops`。新的路线请求不再要求顶层 `point_id`。
- 图片、视频和打卡依旧关联具体 `point_id`。公开/后台体验响应增加实际 `campus_id`；端点路径沿用 [43](43-voice-media-tours.md)，完整字段见生成的 [31 接口参考](31-api-reference.md)。
- 上一批新增的迁移 **`0008_campus_tours`** 为体验记录增加校区外键，使路线记录不再绑定单个地点。升级从原有地点关系回填校区，保留原草稿/已发布 JSON、审核说明和版本号；旧路线读取时兼容转换为校区归属。
- 旧路线里不再使用的原“主地点”下架，不应使其余站点均有效的整条路线消失。任一实际站点或引用视频失去公开资格时，路线仍会停止公开；读取、保存、审核以及助手动作分别执行校验。
- 操作员权限继续覆盖新稿和当前公开稿的全部站点，不因取消主地点而放宽范围。校园路线操作记录属于校区内容：拥有整校区权限的编辑员/审核员可以查看本校区路线审计；仅获部分点位权限的账号不会看到整条路线的校区级审计。审核说明仍可在授权路线工作台查看。

## 部署与回退

本次没有执行生产部署或迁移。按服务器现有版本选择下面一种流程，保留现有 Compose 项目名、配置及数据卷。

### 已部署校园路线版本，数据库为0008

本次仅更新 web（包含 nginx 配置），没有 API 或数据库变更。等待本次最终提交 CI 完成后拉取开发分支，在现有项目目录执行：

```bash
docker compose build web
docker compose up -d --no-deps web
python3 scripts/smoke.py http://127.0.0.1:8080
```

无需重复运行迁移、重启 API 或重导地图、楼层、点位、路网和媒体。刷新页面确认已载入新前端，再测试外部全景入口。此补丁回退只涉及 web 镜像；回到嵌入旧版本也会恢复其已知的打不开问题。

### 仍停留在43所述0007或更早版本

校园级路线的数据结构尚未升级，仍须完成本篇上一批的0008迁移，不能只更新新前端。先备份数据库及媒体/楼层卷，记录原镜像和配置；API与web一起升级：

```bash
docker compose build api web
docker compose run --rm --no-deps migrate alembic upgrade head
docker compose up -d --no-deps api web
docker compose exec -T api alembic current
python3 scripts/smoke.py http://127.0.0.1:8080
```

检查 Alembic 为 `0008_campus_tours`，现有路线、草稿、楼层、全景链接和导航可读。公开访问端口按现有配置替换。媒体上传所需 ffprobe、卷和100MiB代理限制沿用43。不要执行 `down -v`、旧种子或重复地图导入。

涉及0008的完整回退必须一起核对 API 镜像、数据库版本和路线字段兼容。虽然迁移提供降级适配，降级会把校区路线重新关联到站点；不得在含新增内容的生产库上直接试跑。先在隔离环境验证备份，再由部署方执行回退。

## 验收记录与清单

上一批针对性自动测试覆盖校园路线归属与站点范围、旧数据迁移兼容、保存后提审、站点搜索与重排、浏览历史和工具栏未完成形状保护。本次验收另需覆盖安全外链、访客明确点击后打开、旧分享链接和不生成 iframe 的行为；实际执行结果与最终 CI 以 `VALIDATION.md` 为准。不把本地 SQLite 迁移测试当作生产 PostgreSQL迁移已执行，也不沿用上次 CI 结果代替本补丁验收。

部署后至少核对：

- 在有一个及多个全景的地点点击全景入口，确认直接在新标签页打开正确的公开网址和场景；Twin NKU 页面不显示 iframe。
- 通过小开询问全景，确认先显示经过核验的入口，只有访客点击才打开外部标签页；连续语音回答不自动弹窗。
- 打开旧 `?point=…&panorama=…` 分享链接，确认显示原网站入口；资料下架或读取失败时不能继续打开已失效目标。
- 回到 Twin NKU 后小开消息、校园路线站点与导航保留；语音如已暂停，可以明确点击恢复。不要将学校原网站中没有小开浮窗当作本站状态丢失。
- 在原网站检查画面、旋转、场景切换和全屏，记录真实浏览器与结果。
- 建立跨多个地点的同校区路线，调整首站、修改各站文案及视频，再跨账号审核。旧主地点与真实路线站点的下架影响分别正确。
- 地图点位、楼层/VR资料和路线分别执行一次“保存并提交审核”；断网或提交失败后草稿仍可恢复，提交者仍不能审核自己参与的版本。
- 路网普通编辑直接可达；更多工具可用键盘展开，弧线与描线模式仍可操作；未完成绘制不能被保存成正式道路。
- 手机与桌面检查页面窄屏、键盘焦点、返回入口、错误提示及长表单操作。自动组件测试不替代实际视觉验收。
