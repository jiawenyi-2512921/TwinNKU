# 道路与智能导览后台操作

## 管理范围

| 入口 | 可维护内容 | 生效方式 |
| --- | --- | --- |
| 地图点位 | 名称、介绍、公开范围、坐标、点击轮廓 | 既有草稿与独立审核 |
| 资料中心 | 标注楼层原图、同层分区、VR链接与来源 | 既有资源审核 |
| 道路与导航 | 路网、路口、转折点、建筑入口、道路与通行属性 | 整张地图路网作为一个版本独立审核 |
| 智能导览设置 | 问答/导航启停、自动动作、动作白名单、小时额度 | 管理员保存即影响新请求，记录审计 |
| 工作台 / 审核中心 | 原有资料待办和道路路网待办入口 | 从待审入口进入对应地图核对 |
| 操作记录 | 原有编辑审核记录与navigation.*、guide.settings | 可搜索查看变更人、原因和版本 |

前台入口由真实配置与公开资料决定。后台不会凭开启某个开关创造不存在的楼层、全景或道路。

## 角色与范围

路网影响整个校区，要求管理员，或获得该校区全部点位范围的编辑/审核/只读成员。只分配了个别建筑scope的成员不能读取或修改整张路网。

- 编辑员/管理员：编辑和保存草稿，提交审核，撤回待审。
- 审核员/管理员：查看草稿地图和试算，填写说明后发布或退回；参与过本次编辑或提交的账号禁止自审，即使后来切换角色。
- 只读成员：查看授权校区路网，不可保存/审核。
- 系统运行设置：仅管理员读写，操作进入审计。

## 第一次建立路网

1. 打开“道路与导航”，选择目前使用的校园底图。
2. 选择“沿道路连续绘制”，沿真实道路依次点击路口和转弯处。点击已存在节点可接入原路；切回“选择/拖动”结束一条道路。
3. 将实际道路交汇节点设为“路口”，仅用于曲线形状的点设为“转折点”。交叉道路必须共用节点才能连通，不能仅在视觉上交叉。
4. 在建筑真实门口添加节点，设为“建筑入口”，选择所属建筑。一个建筑可有多个入口；系统会在已核实可用的入口之间选路。不要把建筑中心作为入口，也不要画穿楼、跨河或穿围墙的捷径。
5. 点击每条道路，填写名称、方向、关闭状态、无台阶情况和核验依据。单向箭头按“起节点→终节点”定义。
6. 只有有测量依据时填写实际米数。未知值留空，不用像素长度伪造距离。无台阶情况未知时保持“尚未核实”，不会用于无台阶路线。
7. 确认实际道路、出入口及当前通行条件后，勾选“已核实”；依据注明核查人、日期、参考资料或现场核对记录。关闭路段可以保留，但不参与计算。
8. 填写整张路网的来源、入口核对与适用范围说明，保存草稿。

绘制过程不会自动发布。拖动节点后，相连路段的核实标记会清除；修改方向、关闭、无台阶或长度也需要重新核对。可以搜索名称/建筑，按路口、转折点、建筑入口、道路筛选。删除节点时会同时移除相连草稿路段，并要求确认。

## 试算与审核

保存后选择试算起点、终点，点击“试算已保存草稿”。蓝线仅为后台草稿预览，不是对外路线。检查：道路是否真正连接、入口是否正确、折线是否跨过建筑/水域、单向是否正确、存在封闭时能否绕行。

确认后填写提交说明并送审。编辑者退出，由另一审核账号登录。待办会出现在工作台与审核中心的“道路路网待审核”区域，也在侧栏显示数量；进入道路工作区，查看地图、试算和依据后审核。发布修改整张图的路网版本，不逐条发布半张断开的路网。

被退回后查看审核说明，修改并重新提交。待审期间禁止直接覆盖草稿，先撤回再改。保存/审核携带expected_revision，过期版本返回冲突，必须重新载入，不能覆盖其他人的修改。

## 日常维护

- 道路临时封闭：在当前路网建立新草稿，把相应路段设为关闭，填写原因，独立审核发布。
- 道路恢复：取消关闭，重新核实通行情况并提交审核。
- 新建筑入口：在真实入口加节点，关联地点并接入道路，核实后发布。
- 道路改线：拖动节点或重建相关路段，保留旧公开版本直到新版本审核通过。
- 底图版本变化：旧路网自动停止对外算路。后台显示版本提示；使用新底图后全部路段需重新核实，不能静默沿用旧坐标。
- 点位下架：相关入口不再参与公开导航，避免经过已撤回地点的入口作为捷径。

前台每30秒或重新聚焦时核对路网；路线有效期5分钟，过期或版本变化后清除高亮并提示重算。客户端断网或路网状态无法读取时不把旧线当作当前有效路线。

## 智能导览设置

“学校应用API已配置”只表示服务器配置完整，不是连通性探针。用公开网页实际问答确认学校服务可用。

管理员可独立开关小开问答、已审核路网导航，以及定位/楼层/VR/路线四类网站动作。关闭自动动作后，用户通过卡片手动打开；VR一直要求用户点击。修改小时额度必须结合学校配额，不能据此突破学校限制。

变更填写原因并保存，后台显示版本与最近说明。额度和动作开关由后端执行，不能只隐藏按钮。公开配置最多60秒刷新，但后端新请求会立即检查当前设置。

## 已知范围

本批提供系统化维护入口；实际校园道路和门口仍需团队采集、核对和审核。没有加入全校室内路网、实时定位、自动时段规则、语音和主题任务编辑，这些尚未实现，后台没有假开关。学校知识库与智能体核心提示词仍在NK-GeniOS管理。

建议先完成两栋楼之间的一条真实路线，再逐步接入主干路和建筑入口。功能验收以公开页面实际算路、AI调用结果和现场资料相符为准。
