# 访客体验、界面与前端实施规范

对应MAP/RES/AI/TOUR需求；本轮地图、目录、详情、楼层减负已在代码实现。对话、主题、回顾等是后续目标。开发时保留这一套交互，不再为每个新模块追加常驻侧栏。

## 1. 信息架构与导航

首页是地图，不放大幅欢迎页、功能宣传卡和滚动建筑大全。顶部只保留品牌、校区、搜索、目录、帮助；刷新收入帮助。地图工具只负责放大、缩小、回全图。后台独立位于/admin。

主内容上下文只有一个：目录 / 地点 / 对话 / 主题步骤。目录打开时暂隐地点详情但保留选中状态；点目录结果后目录收起。楼层大图是独立模态查看器，背景地图保持挂载。VR外链在新窗口打开，返回后保留上下文。

| 页面状态 | 可见内容 | 主操作 | 退出行为 |
| --- | --- | --- | --- |
| map_idle | 地图、紧凑搜索、工具、简短提示 | 搜索/选点 | 不适用 |
| directory | 地图+可滚动目录；分类只在目录内 | 选择一项 | 关闭目录回原地图/详情 |
| point | 名称、类别、介绍、实际可用资源、分享 | 有楼层则楼层；否则阅读/VR | 取消选中，焦点回目录按钮 |
| floor | 建筑标题、层/区选择、原图、缩放/1:1、返回 | 查阅楼层 | 关闭大图并清floor参数，保留建筑 |
| chat（计划） | 当前上下文摘要、回答/来源/动作卡片、输入 | 提问/取消 | 收起对话不强迫用户丢失地图 |
| tour（计划） | 当前站、进度、讲解、观察任务 | 下一站 | 先保存进度，再返回自由探索 |
| recap（计划） | 实际访问、要点、未完成项、来源 | 继续/分享/结束 | 清楚区分结束和删除记录 |

不采用“同时显示地图目录+地点详情+聊天+主题大面板”的四栏方式。一次只要求用户完成一个任务。AI入口只有能力真实启用后出现。

## 2. 本轮已实现的组件职责

- App：目录可见性、搜索/分类、选中点位、公开目录同步、顶层快捷键。地图始终位于可扩展主区域。
- MapCanvas：Leaflet生命周期、图块、点击轮廓、随图文字、选中区域聚焦、视角工具；不读取聊天内部状态。
- PointDetails：标题/介绍/资源入口/分享、手机展开收起；不按名称类别猜楼层。
- FloorPanel：仅查询当前点的已发布楼层，过滤无标注图条目；处理请求取消、轮询、深链接、合法分区与模态窗口。
- FloorViewer：仅加载当前原图，在Leaflet中显示；UI缩放不重编码原图，1:1为图像像素与地图像素同尺度。
- PanoramaPanel：已发布资源卡片、来源域名、新窗口入口；没有资源时隐藏空区块，网络失败保留重试提示。
- PointIntroduction：纯文本段落与有限来源尾注解析；不直接渲染任意HTML/Markdown。

## 3. 桌面、平板、手机布局

| 条件 | 规范 |
| --- | --- |
| >1000px | 紧凑单行头部；地图占其余区域；目录左侧340px，详情右侧360px，二者不并排常驻 |
| 761—1000px | 隐藏重复校区文字；搜索自适应；详情不超过360px |
| ≤760px | 顶部两行：品牌/帮助、搜索/目录；地图占剩余；点位底部卡片默认最高46dvh，可展开 |
| 320/360px | 长标题换行；输入和按钮不挤出视口；必要时隐藏重复校区文字 |
| 手机楼层 | 100dvh模态大图；safe-area边距；层/区选择与返回均可操作 |
| 低高度/横屏 | 内容区内部滚动，关闭按钮固定在面板头；不让全页滚动挤走地图工具 |
| 桌面200%缩放 | 自动采用窄屏布局；不能依赖鼠标悬浮才能取得核心内容 |

手机底卡展开应为显式按钮，未来再决定是否增加拖拽手势；任何拖拽都须有按钮等价操作。底卡收起/展开不修改地点位置。键盘弹出后输入可见，提交状态和取消按钮不能被键盘永久遮挡。

## 4. 视觉系统

使用原生CSS变量，延续南开紫，避免为“高端感”引入新UI框架。基础token：主文字#302b34、次文字#6c6472、强调#69346d、边框#e7e2e9、白色面板、轻灰紫输入底。颜色调整需做真实对比度测量。

正文14—16px、行高1.75—1.85；主体标题20—24px；次级提示≥12px为常规目标，像素信息等辅助信息可11px但不得承载主要操作。中文以系统字体为主，不依赖大体积外部字体。面板圆角16—18px，间距以4px倍数组织，单层轻阴影，不叠加大面积毛玻璃。

交互主按钮最低44×44 CSS px为本项目体验要求；这比WCAG2.2 AA的目标尺寸24px基线更严格，并不意味着网站已通过WCAG认证。正文对比度目标≥4.5:1，大文本≥3:1，重要边界/焦点≥3:1；需要测量，不按色值“看起来够”判断。

地图图内文字不做低清重绘；小比例尺读不清时用搜索/选中详情补充名称。不能重新铺满编号/浮动白标签，也不能以放大CSS字体替代原图保真。

## 5. 搜索完整行为

1. 输入长度上限120，与既有接口契约一致。当前目录规模83，先本地名称/别名过滤；未来>2000点再以性能证据考虑服务端搜索。
2. 搜索框获得焦点打开目录；Esc收目录但不清搜索；清空按钮清词且保持输入焦点。
3. 中文输入法候选提交期间Enter不选点；确定文本后Enter选当前首项。空结果不能选上次结果。
4. 分类与文本AND组合；无结果提供清除分类并查看全部，不能留下不可恢复空面板。
5. 用户输入为普通文本，不拼HTML；别名和类别来自公开目录。未命名/未映射点不绕过现有地图过滤规则。
6. 列表行整行点击，名称优先、类别辅助；长名称自然折行。顺序稳定，同名需校区/地点类型辅助辨认。
7. 搜索结果条数使用温和status，不每个键重复朗读整列；不在83个标签间制造冗余焦点。

## 6. 地点/楼层上下文与URL

当前参数：point=UUID、floor=UUID、floor_section=小写分区slug。无关channel、utm等参数保留；切换地点清除旧floor/section，同地点重选保留合法floor深链接。无楼层、跨楼层ID、下架资源回退合法可用项或关闭查看器。

点位详情采用稳定point ID作为key。发布后相同点位字段更新不重建整张地图；map/revision改变才重建地图资源。API失败不把上一地点的数据错挂到新地点。组件卸载AbortController取消请求，晚到结果禁止写新URL。

楼层普通入口只在打开大图时写floor参数；后台轮询不能因为读到了楼层自动让首页进入楼层。深链接首次校验通过可直接打开；关闭后轮询不再次弹出。关闭只取消floor/section，不取消point。切换楼层默认选该层合法首区，切分区只更新section。

未来路由需将tour/chat等状态接入统一ViewContext，迁移前保留旧point/floor链接兼容。当前仍使用replaceState，不宣称已有完整浏览器前进后退历史栈；要改pushState时必须补popstate和状态恢复回归。

## 7. 空、错、加载与失效状态

| 情况 | 呈现 | 禁止行为 |
| --- | --- | --- |
| 首次地图加载 | 清楚的读取状态 | 永久骨架不报告错误 |
| 系统无地图 | 准备中+重试 | 伪造地图或演示数据冒充正式 |
| 目录刷新失败 | 保留上次快照并提示重试 | 清空用户刚选内容且不解释 |
| 图块部分失败 | 局部警告+重载图块 | 拖垮全部页面 |
| 资源确实为空 | 隐藏无用入口 | 猜楼栋应该有楼层而给空按钮 |
| 资源请求失败 | 明示暂时读不到+重试 | 当作没有资源静默隐藏 |
| 图片坏链 | 图片区域重试，保留返回 | 锁住模态窗口 |
| VR不可访问 | 显示外部来源，可回地图/报告问题 | 自动换成无关全景 |
| 内容撤回 | 清除不可见选择/动作，允许回到地图 | 继续展示已知撤回的缓存 |
| AI失败 | 当前问题可重试/取消，静态资料可用 | 用固定答案假装真实模型成功 |

## 8. 无障碍与输入控制

- 语义化header/main/aside、可见或sr-only标题；跳到地图链接有效。不能把整页只做成canvas。
- 图上点击区域有role/button、可读名称、Enter/Space；目录作为等价路径。
- 地点标题在选择后接焦点，关闭回目录按钮。楼层原生dialog承担焦点约束，Esc仅关闭当前大图，不同时取消地点。
- 没有弹窗时Esc按帮助→目录→详情顺序退出；输入框/textarea/contenteditable内的/不触发全局搜索。
- 异步错误用alert，加载/复制反馈用status；不要把正常轮询结果作为不停打断的告警。
- reduced-motion关闭不必要动画；自动平移可关闭；放大按钮有文字辅助名称。
- 发布前至少NVDA或VoiceOver一次完整任务。自动检查不足以证明可用性。

## 9. 后续AI/主题共用的前端基础

拟新增AppContext：campusId、pointId、mapId/revision、floorId/section、tourPlanId/revision、mode、contextRevision、activePanel。原图坐标不进入聊天组件局部状态。用户切换上下文revision递增；AI自动动作只能在产生时对应revision仍一致时执行。

ActionDispatcher按type映射模块命令，不执行返回HTML和脚本。focus_point完成公共资源读取与选择才ack applied；open_vr只生成用户可点击卡片，用户点击前不ack已打开；跨站内部加载不可证实就只统计“点击进入”。重复action_id去重；晚到动作展示“此前请求已过期”而不抢当前地图。

聊天文字按验证后内容显示，来源折叠展开；回答中资源卡片可解释“查看图书馆”“打开二层图”。输入支持取消与重试，不能隐式重发已接受turn。主题面板展示当前/总数、当前标题、下一站，更多选项收纳跳过/缩短/结束。

## 10. 前端验收任务脚本

| 用例 | 操作 | 必须观察 |
| --- | --- | --- |
| UX-01 | 首次进站→目录→图书馆 | 无常驻长目录；一个详情；地图可继续缩放 |
| UX-02 | 搜索→输入法→Enter→无结果→清除 | 无误选、无横向溢出、焦点合理 |
| UX-03 | 打开图书馆→楼层→1:1→返回 | 单次进入；原图请求不变；地图状态保留 |
| UX-04 | 同层多区→复制深链接→新开 | 层/区一致，非法分区有合法回退 |
| UX-05 | 看无资源地点→断网看另一点→重试 | 空与失败区分，不显示上个点资源 |
| UX-06 | 关闭大图→等待轮询→再进 | 不自行重开，不把关闭动作写成下架 |
| UX-07 | 390×844、320×568、844×390、桌面 | 搜索/关闭/楼层工具≥44px；核心不遮挡 |
| UX-08 | 键盘/读屏完成任务，减少动态效果 | 焦点可见、Esc层级正确、有替代地图点击路径 |
| UX-09 | 发布改名/移动/下架后回前台 | 跟随公开更新且不重置其他地图数据 |

本轮实际执行情况以VALIDATION为准；该表是部署后的必测任务，不是全部已通过证明。

参考：[W3C WCAG2.2](https://www.w3.org/TR/WCAG22/)、[目标尺寸AA](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)、[Leaflet CRS.Simple](https://leafletjs.com/examples/crs-simple/crs-simple.html)。
