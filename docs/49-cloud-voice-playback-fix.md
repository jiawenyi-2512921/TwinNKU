# 云语音无声修复与验收

更新：2026-09-30。基线为开发分支 `feat/admin-console` 的 `8932093`。用户已提交 Qwen3 TTS 接入，并反馈“没有声音”；本次接续这些提交，保留 Cherry 音色、模型降级、缓存与限额。基线 CI 已成功，但不代表目标设备出声。

## 定位到的代码问题

1. 麦克风对话仍调用 `voice.ts` 的浏览器朗读。`announce()` 在语音轮流交流时退出，所以接入的云音色只覆盖文字回答，没有覆盖主要语音流程。
2. 旧 `unlock()` 在首次手势、尚未进入 `cloudPaused` 时直接返回。拒播后用另一个临时静音元素“解锁”，真正回答和每段回答却重新创建 `Audio`。WebKit 播放许可按元素处理，应该复用播放器。初次解锁用的 `data:audio/wav` 也不被当前 Nginx `media-src` 允许。
3. 系统朗读回调没有区分 `onend` 与 `onerror`；没有系统声音也调用 `done()`，被当作朗读成功。失败提示优先级低于上一次回答，用户看到字幕却看不到原因。
4. 音频取消没有中止合成请求、完成等待中的播放 Promise；关闭小开、视频播放和后台切换只覆盖原浏览器语音，文字回答的云音频可能继续或迟到播放。一次服务失败会永久禁用本页云语音。
5. 后端把 `/api/v1` 固定追加到 `VOICE_BASE_URL`，填写官方 SDK 的 `/api/v1` base 会变成重复路径；上游连接/超时异常没有转为已有可恢复的 503。

这是代码定位，不能据此断定用户设备只受一个原因影响。本次未读取服务器密钥或登录服务器；线上状态 GET 在当前环境无法读取，真实服务商调用、音量和手机播放待部署方验证。

## 修复后的行为

- 文字与麦克风回答共用同一个云播放器。浏览器识别仍负责语音输入；回答经学校问答后交给当前云 TTS。没有把语音识别也改成云服务，没有宣称全双工或端到端流式。
- 在点击小开、进入文字交流或发送问题时，同步初始化一个持久播放器，以 `blob:` 静音 WAV 进行首次播放准备；后续回答复用此元素。无需放宽 CSP，也不监听地图上的所有点击/键盘操作。
- `NotAllowedError` 或播放无进展时保留当前音频，字幕提示点播放图标。该图标在点击回调里直接继续同一份音频，不重新合成、重复计费或重复朗读回答。用户/浏览器禁止自动播放时仍可能需要这次点击，不能保证静音准备在所有设备上解除限制。
- 实际播放事件和完成/失败事件驱动角色状态。云文件没有词级时间戳，字幕仅显示当前真实片段的短句；系统朗读沿真实 boundary 事件更新。没有伪造进度、声波、口型或已听见声音的指标。
- 合成请求等待至多45秒，播放器等待有超时保护。取消会中止请求、停止音频、清理事件/计时器/Blob URL，并完成等待。关闭、后台、视频和新对话都会取消；旧回答/回调不会重新启动麦克风或播报。
- 服务/解码失败才尝试系统朗读，依据结束/错误事件返回结果；两条链路均失败时提示并提供重试图标。部分云片段已播完时，只降级剩余文本。暂时服务失败冷却60秒后可再尝试，不再整页永久禁用。
- 后端兼容服务 origin 与带 `/api/v1` 的 SDK base；上游传输异常转为 `VOICE_SYNTHESIS_FAILED` 503。超时不自动重试，以免请求已计费却再次调用。模型/音色/限额保持用户提交的配置。

先执行只读检查（不验证实际合成）：

```bash
curl --fail-with-body https://2512921.cn/api/v1/voice/status
```

- `enabled=false`：运行中的 API 没有启用语音配置；模型在控制台开通不等于 API 容器已获得配置。
- 404：运行中的 API 尚未包含语音模块，或同源代理路径不匹配。
- `enabled=true`：只说明配置启用；继续检查真实合成，不能算出声验收。

以下小样检查会调用现有合成端点，可能消耗额度；不要把 WAV 二进制打印到终端。响应错误 JSON会存到文件，先检查 HTTP 状态/MIME，再用设备播放器打开。

```bash
curl --fail-with-body \
  -H 'Content-Type: application/json' \
  -d '{"text":"你好，我是小开。"}' \
  -o /tmp/twinnku-voice-sample.wav \
  -w '\nHTTP %{http_code}; type %{content_type}; bytes %{size_download}\n' \
  https://2512921.cn/api/v1/voice/speech
```

200/`audio/wav`且设备能播放：云合成链路成立，再测网页；503表示配置/供应商/下载不可用，429表示限额，422表示文本不符合限制。网页拒播会显示播放图标；点图标仍无声时检查系统媒体音量、静音/输出设备和浏览器站点播放设置。反馈只需HTTP状态、公开错误码、设备/浏览器与发生步骤，不发密钥或签名音频URL。
