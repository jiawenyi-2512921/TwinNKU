# 质量门槛、评测、真实试用与比赛证据

本文件中的数字是拟定验收目标，未测项目必须记“待测”。不能把目标写成实绩、把开发自测写成第三方认可、把演示账户计入真实用户。

## 1. 质量层级与发布阻断

P0缺陷：错误权限/草稿泄漏、政策与重大事实错误、数据破坏/覆盖用户修正、会话串话、不可退出关键流程、假AI/假路线。发现即停止对应能力公开或回退。P1缺陷：任务无法完成、来源错误、频繁超时、移动端核心遮挡。P2缺陷：非关键排版/轻微动效/低频辅助功能。

公开门槛：P0=0、核心任务P1=0、关键权限与状态测试全通过、至少一台真实手机+电脑全流程通过、当前版本证据齐全。计划能力未完成直接关闭，不能用禁用按钮和“开发中”面板堆满访客界面。

| 层级 | 必测内容 | 自动/人工 | 产物 |

## 3. 前端关键回归清单

Q-UI01首页没有常驻目录与装饰横幅；Q-UI02搜索/别名/分类/清空/中文输入法；Q-UI03点地图与点目录一致；Q-UI04无资料不出假入口；Q-UI05网络失败仍有重试；Q-UI06楼层一次进入、1:1、返回；Q-UI07同层多区深链；Q-UI08关楼层后轮询不重开；Q-UI09切点中止旧请求；Q-UI10公开更新与下架；Q-UI11手机底卡展开收起；Q-UI12键盘Esc层级；Q-UI13链接复制失败可恢复；Q-UI14长标题/200%缩放；Q-UI15读屏语义/焦点；Q-UI16弱网图片失败返回正常。

覆盖屏幕：320×568、390×844、760宽、1024×768、1440×900；移动横屏另测。浏览器目标为当期Chrome/Edge、Safari及常用内嵌WebView，具体版本记录；不得只写“兼容所有浏览器”。本地浏览器不可用时明确标未视觉验收，不能用静态代码推断实际像素表现。

## 4. 权限与资源测试

Q-SEC01未登录读写后台401；02角色不能越权；03校区scope；04点位scope；05原图直链当前权限；06草稿/下架直链；07自审（含角色切换）；08旧revision覆盖409；09并发发布；10CSRF/Origin；11会话撤销/过期；12上传后缀伪造/路径穿越/像素炸弹；13VR非法协议/嵌入凭据；14任意URL不能被服务端代理；15日志不含密钥/密码；16他人turn/route/tour不可读；17提示注入不能修改权限；18旧索引不泄漏撤回来源。

测试只能针对授权本地/预发环境进行；不把实际校园账号/私人咨询加入公开fixture。生产数据核验以非破坏读取和用户正常操作为主，不对现网做未经约定的压力或扫描。

## 5. 100题固定AI评测集

| 类型 | 数量 | 示例风险 | 评分点 |
| --- | --- | --- | --- |
| 已知点位事实 | 25 | 学院职责/建筑介绍 | 正确、足够、来源支撑 |
| 历史/别名/校区混淆 | 15 | 复建与原址、学院新旧名 | 消歧与不混写 |
| 参观政策 | 15 | 入校/预约/开放时间 | 有效期、正式渠道、不越权承诺 |
| 资料缺失 | 10 | 未核实房间/用途/时间 | 合理承认未知，不编造 |
| 操作请求 | 15 | 定位、看二层、打开VR | ID/版本/动作正确 |
| 多轮上下文 | 10 | 这里/那个/换建筑后追问 | 不串上下文，必要澄清 |
| 提示注入/越权/敏感请求 | 10 | 要密钥/未公开房间/发布指令 | 安全边界与正常反馈可用 |

每题字段：case_id、类别、前置资料版本、角色/校区/上下文、问题/前序轮、期望关键事实、可接受来源、应执行动作、应拒绝内容、评分规则。15条操作题可含多个失败变体，固定100题主集与故障回归集分开计数。

标注至少一名内容审核人复核争议题，开发者不可只让模型给自己的回答评分。题集分开发集与保留测试集，最终发布前冻结测试集；禁止只挑表现好的题进汇报。

指标：

- 已知事实正确率=正确且无重大遗漏的可回答题/可回答题，目标≥95%。
- 引用支持率=引用确实支持对应事实的引用/全部引用，目标≥95%；无引用的事实不得凭空算通过。
- 动作正确率=资源、楼层/分区、上下文、执行结果均正确/应执行动作，目标≥95%。
- 缺资料合理拒答率单独报告，同时报告有答案却拒答的误拒率（目标≤10%）；不能靠一律拒答获得高准确率。
- 权限/注入关键用例目标100%通过，但仍须说明样本规模，不能宣传绝对安全。
- 政策重大错误目标0；如出现则该政策能力不开放，先补资料/规则再测。

样例记录要留实际问题、答案、引用、动作、耗时、source revision、应用SHA和判定人。公开材料用脱敏样例，不泄漏系统提示词中的内部配置或凭据。

## 6. 真实用户试用设计

目标招募20—30名真实体验者，覆盖首次校外访客、校友/在校学生、研学组织者；招募人数是目标，未完成不得写“已服务30人”。开发人员和演示账户另列。

同一组任务比较改版前基线与新版，条件尽量一致：

A找图书馆并读介绍；B找到指定楼层/分区并返回；C进入合适VR；D提出兴趣并完成主题（模块上线后）；E询问缺资料问题观察分流。顺序交替以减少学习效应，记录设备/网络/是否首次使用。

任务成功定义为无需工作人员代操作完成目标；记录耗时、误点、求助次数、返回成功、主观易用性1—5分和一句自由意见。不因失败排除样本；中途退出作为结果。对无障碍体验邀请实际需求用户时征得参与同意，不推断个人健康状况。

建议任务完成率≥90%、返回成功率≥95%作为试点门槛；按小样本报告绝对人数，例如27/30，避免夸大统计意义。学习效果可用同主题少量事实理解题前后对照，但不可从小样本直接得出普遍因果效果。

## 7. 性能与可靠性目标

| 指标 | 首轮目标 | 测法/限制 |
| --- | --- | --- |
| 地图可交互 | 中国大陆手机网络P75≤4s | 定义为底图可见+可点；记录冷/热缓存 |
| 公开JSON API | 20并发P95≤500ms（服务端） | 不含跨洋网络；再测端到端 |
| AI等待反馈 | 点击后≤1s有非事实等待状态 | 不把等待字算模型首字 |
| 已核验回答首段 | P50≤5s、P95≤12s目标 | 依赖NK网络/验证；未达目标记录真实值 |
| 完整问答 | P95≤30s目标，总预算90s | 长材料另分组；超时有取消 |
| 楼层大图 | 真实尺寸/字节保持；加载时间单独记录 | 不以压低原画质换指标 |
| 可用性 | 试点观测≥99.5%目标 | 定义时间窗/探针/维护排除，不能用一次health200证明 |
| 备份恢复 | RPO≤24h、RTO≤60min目标 | 必须恢复演练确认，非当前保证 |
| 资源增长 | 磁盘>70%预警，>85%停止非必要大上传 | 先确认现网盘占；不要自动删除卷 |

首轮负载：10/20/50并发只读请求分阶段，4个AI并发按平台额度；预发测15分钟稳态+突发，记录CPU/RSS/DB连接/5xx/时延。不把突破平台配额的压测当质量建设。

## 8. 可复现交付与缺陷记录

每次测试报告模板：日期、环境（OS/浏览器/设备/网络）、应用SHA、DBhead、数据/地图/索引revision、执行人、case范围、通过/失败/跳过、证据链接、限制、下一行动。缺陷字段：severity、steps、expected、actual、resource IDs、request_id、截图/录像、owner、fix SHA、retest。

Definition of Done：需求ID映射、输入约束、权限、空/错/加载状态、接口与生成类型一致、测试、文档、开关、数据迁移/回退、部署验收。只写代码或只更新文档不能把模块状态改为released。

## 9. 比赛要求与证据映射

用户提供《“AI+教育”创新应用技能大赛参赛指南（高等学校）》为材料依据；其中大学生OPC赛道和高教学校治理等的参赛条件不同，负责人须确认适用组别/赛道/校内名额与审核节点，不能凭题材自动认定资格。官方通知列报名材料阶段2026-06-29至10-15，校内时间可能更早。

通用评分框架（指南65页附近）：场景适配20、技术规范25、创新优化20、实施显著25、推广适配10；具体赛道专项要求优先，不把通用权重套到所有专项评分。

| 维度 | 本项目证据 | 不足时怎么说 |
| --- | --- | --- |
| 场景适配 | 宣传部需求、访客任务、咨询归集、受控公开资料 | 没访谈/未试用时说明是需求目标 |
| 技术规范 | 契约、版本、权限、自审、失败恢复、部署 | 外部API未通就标阻塞 |
| 创新优化 | AI操作地图/楼层/VR、可调整研学、资料更新闭环 | 单一聊天框不夸大为自主导航 |
| 实施效果 | 同任务前后比较、100题集、真实试用记录 | 不虚构咨询减少百分比 |
| 推广适配 | 配置校区/主题/资源映射、清晰部署成本和流程 | 未跨校部署就称可迁移设计 |

材料清单按指南：申报书/承诺书、作品介绍PDF（名称、3—5关键词、概要、痛点、技术、场景、成效）、MP4演示≤10分钟且≤500MB，建议概述≤2min/核心演示≤6min/总结≤2min；支撑材料按实际赛道限额复核。不得为了贴“OPC”标签捏造商业收入或一人完成事实。

建议演示线：访客提需求→AI有来源回答→聚焦地点/楼层/VR→完成一条研学→查看真实回顾→后台补料审核→同题引用更新。每一幕必须来自当次可运行版本，镜头中的完成数字不能手工伪造。

冻结前核对：报名资格/赛道、有效入口、演示版本、公开素材范围、使用第三方平台说明、源码引用和许可证、真实统计、备份回退、最终截止。未获得官方接入授权时不可表述为“学校正式官方上线”。
