# 主题研学、参观回顾与路线开发规范

目标是让用户完成一次有内容、有观察、有反馈的线上参观。本文是未实现模块设计，不给现有地图冒加未核实路线。

## 1. 两种“路线”必须区分

| 对象 | virtual线上导览 | walking线下步行 |
| --- | --- | --- |
| 本质 | 经审核内容的访问顺序 | 真实可通行路网中的路径 |
| 必需数据 | 主题、站点、讲解、媒体、学习目标 | 左列+入口、路网、时段、封闭、标定 |
| 时间 | 预计阅读/观看内容量，注明估计 | 有实测长度与速度假设才能估算 |
| 图上表现 | 当前站与下一站；不连接成假步行线 | 按图版本返回的segments绘制 |
| 首发优先 | P0，独立于室外算路 | P2，有数据后启用 |
| 不确定情况 | 可缩短内容或跳过 | 明确不可达/缺数据，不能直线穿建筑 |

旧06把M06一概依赖M03：新决策将M06 virtual与M03解耦；walking仍依赖M03。开发不得因尚无实测路网阻塞线上主题，也不得把内容排序称作精确导航。

## 2. 主题内容模型

模板包含id/revision/campus/theme/title/summary/audience/goals/difficulty/locale/stops/duration_estimate/source_refs/status/reviewers。每站包含stop_id、point_id、content_id/version、optional_scene_ids、optional_floor_id、observe_task、reflection_question、expected_reading_seconds、optional/required。

模板目标不超过3个可观察的学习目标，例如“能区分历史原址与津南复建纪念建筑”“能以一处可见细节解释某段校史意义”。不能以“感受伟大/提升素养”作为唯一不可检验目标，也不对参与者作思想评价。

首条建议“南开校史与爱国传统”，候选站包括周恩来雕像和思源堂、秀山堂、木斋馆等已核实点；最终顺序须内容人员确认。候选不自动恢复用户已撤销的点位。正式模板只引用审核版本，资料不足可减站，不填编造故事。

## 3. 三条目标主题的差异

| 主题 | 用户任务 | 站点选择逻辑 | 回顾结果 |
| --- | --- | --- | --- |
| 校史与爱国传统 | 理解人物、办学历史与校园纪念空间 | 人物/事件/历史与现址有明确证据 | 时间关系和核心故事，标明来源 |
| 学科探索 | 了解学院与交叉研究如何关联 | 用户兴趣→2—4个学科点→交叉中心 | 兴趣匹配解释，不做升学保证 |
| 校园生活 | 初步认识公共服务和学习生活空间 | 图书馆、活动中心、餐饮等公开点 | 设施与官方信息入口，不猜营业/入校政策 |

第一条完整通过再扩展，不能复制同一组点位只改主题名。20/30分钟等选项表示内容量预算，不保证用户真实阅读速度。

## 4. 编排算法

第一版“审核模板+确定性约束”优先，AI仅解释选择或在合法候选集中建议顺序。输入：campus_id、theme、mode、duration_minutes 5—240、preferred_point_ids≤20、start（walking必需）、可选语言/讲解深度（新增字段须先改契约）。

处理：

1. 验证所有点和模板当前公开，取固定模板版本快照。
2. 过滤与校区/公开范围/用户要求不一致的资源。
3. 保留required站，按内容依赖排序；optional站按兴趣相关度与阅读预算选择。
4. 若最小内容超过预算，说明需要更长时间或提供简洁版，不能默默违反约束。
5. virtual不调用算路、不填写米数；walking必须连通且满足访问时段。
6. 保存生成依据、模板版本、选中/排除原因、计划revision及过期时间。
7. 返回TourPlan和每站内容引用；不把模型自由文本当可执行计划。

推荐候选排序可用score=主题相关度+明确兴趣加分−重复内容惩罚，权重作为可调配置并记录版本；没有训练/验证数据时不用“智能最优路线”宣传。随机排序需可重复种子且仅在同等合法选择间使用，比赛首版默认稳定结果。

## 5. 计划与步骤状态机

计划：created→active→paused/completed/abandoned；expired为不可继续的终态。步骤：not_started→viewed→completed，或skipped。viewed表示打开内容，completed须用户明确“完成本站”或完成定义好的轻任务；浏览时长只作辅助，不等于学习达成。

| 操作 | 规则 | revision/记录 |
| --- | --- | --- |
| 开始 | 验证仍有合法起始站 | plan revision+1，started_at |
| 下一站 | 当前站记录按用户选择完成/跳过；选择下一可用站 | 事务保存进度与当前stop |
| 上一站 | 可回看，不清除已完成记录 | 记录current_stop，完成数不减少 |
| 跳过 | 明确本次跳过，可之后回访 | skip reason可选，不强制填写 |
| 缩短 | 只移除未完成optional站，保留必需和已访问历史 | expected_revision冲突409 |
| 换主题 | 创建新计划或显式调整，保存原记录 | 不能把新主题伪装成原主题完成 |
| 暂停 | 记当前位置，恢复前复核资源 | 不要求持续在线保持会话 |
| 结束 | 提示已完成/未完成数量，生成回顾 | 不能一键把所有站标完成 |

跨标签页操作比较expected_revision，冲突后展示服务器新进度，用户决定是否继续；不盲目重放“下一站”。网络丢失用幂等操作ID恢复，避免双计完成数。

当前TourAdjustment契约只有shorten/skip/change_theme等，缺少进度提交和状态字段；实现前新增/补齐计划契约，再生成前端类型。草案建议POST /tour-plans/{id}/progress（client_event_id、expected_revision、stop_id、action），不是已存在端点。

## 6. 学习体验与回顾

每站结构：短讲解→关联图/VR观察→一个问题→可选深入。用户可以跳过问题，不制造强制测验障碍。题型分两类：有依据的客观事实题（版本化答案与来源），开放反思题（引导反馈而非对错评分）。

回顾基于实际事件：访问站点、已完成任务、所读内容版本、提出的问题、待探索建议。模型可以润色表达，但不能添加未访问经历和“已掌握某价值观”等判断。

回顾最小内容：主题标题/日期、已完成X/Y、3—5个来自审核材料的要点、用户选择保留的思考、来源链接、继续探索入口。默认不公开原始对话/个人答案。分享只生成可控摘要；原始学习回应需用户主动选择才分享。游客会话清除后无法用公开URL恢复私人记录。

教师任务单P2：模板目标/建议流程/问题/参考依据/当前版本；导出可打印PDF。生成文件应有内容版本和日期，不能自动套学校官方公文标识。多语言先中文稿审核再译，不把模型未经复核译稿宣称官方。

## 7. 室外路径算法与数据条件

路网采集最小字段：节点ID、校园/地图版本、原图坐标、类型（路口/入口/楼梯/电梯）、公开范围；边ID、起终点、折线、方向、通行模式、台阶/坡度/宽度已核实值、时段、封闭状态、实测长度/依据、审核人。

同图像素折线长度不等于米数。只有测量或经核验标定可出distance_m；速度假设须明示且无障碍路线单独评估。没有数据返回null，不填固定4.5km/h再冒充实测结果。

计算：读取有效图快照→按权限/时段/临时关闭过滤→选择已核实出入口→Dijkstra/A*（启发函数仅用合法同单位估计）→拆成map_id/revision/ floor segments→保存图版本和输入→返回。via最多10，校区必须一致。

无障碍模式只走有充分证据可通行边；未知坡度/楼梯状态不能默认为无障碍。不可达返回ROUTE_UNAVAILABLE并说明可以选择其他公开入口；不提出穿围墙或绕过管理的路线。

临时关闭：发布新边状态/图版本，未开始的路线读时失效；进行中提示重算。前端不能把跨图seg直接连成一条直线。官方地理导航P2可给核实坐标的外部链接，与规划图定位分开标识。

## 8. 楼层路线探索边界

现有100张楼层图只证明可看图，不证明图上房间、门、楼梯、电梯已结构化。先一栋、两层、仅公共区域的样板；人工标注并实测入口/走廊/楼梯连接，管理部门确认公开范围。

室内节点与floor revision绑定；更换楼层图必须核对节点坐标。电梯跨层连边明确同一电梯组；楼梯有方向/层差/不可无障碍属性。无公开房间名单时，不OCR后直接开放所有房间检索。AI show_floor可以先完成，与室内算路无耦合。

## 9. 必须完成的验收

TOUR-T01完整一主题从开始到回顾；T02中途换点后回到当前站；T03缩短保留已完成站；T04断线重试不重复计数；T05两窗口冲突；T06站点下架后合法跳过/解释；T07不同主题有独立目标与内容；T08virtual无假距离路径；T09回顾不编造记录。

ROUTE-T01不跨水/楼/围栏；T02入口时段；T03无障碍未知边拒用；T04图版本变更；T05跨层seg；T06不可达；T07未标定返回null；T08他人route_id拒读。没有真实路网时只完成设计/测试图，不能给公众开放walking能力。
