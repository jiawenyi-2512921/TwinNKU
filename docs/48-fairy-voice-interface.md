# 小开精灵与语音优先界面

更新：2026-09-29。用户已确认二维角色，基线为开发分支`feat/admin-console`的`e555580`。本次是web界面与素材交付；不代表服务器已更新。

## 默认交互

平时只保留角色和图标操作。字幕显示识别文字、回答或必要的失败/暂停信息；不常驻姓名标题、状态说明、地点简介和文字输入框。文字按钮打开对话抽屉，展示完整问答、资料来源和动作入口。首次需要访问口令时，由明确操作打开连接界面，不在进入地图时自动申请麦克风。

- 点击角色或麦克风开始/暂停语音。朗读时可用图标打断，再次聆听；视频播放和页面隐藏继续暂停语音。
- 拖动只移动小开，不发送问题或启动麦克风；支持鼠标和触摸。位置以有限的归一化坐标存于当前浏览器，不上传聊天或账号信息。
- 屏幕尺寸、方向和可视区域变化时重新限制角色位置，避免落到屏幕外；键盘方向键可移动角色。存储失效时退为当前页面位置。
- 收小图标暂停交流并缩小角色，点击角色恢复；文字抽屉收起后角色仍在。字幕和抽屉不随拖动越出屏幕。
- 导航、楼层、校园路线、打卡等继续调用既有核验动作。默认界面中的对话图标在有资料时带提示点，点击查看完整操作列表；VR被浏览器拦截时保留核验后的原站链接图标。

## 形象与动作

素材基于用户2026-09-29确认的二维角色：银紫头发、精灵耳、银杏发饰、南开紫披肩、校徽、导览地图。六姿态按待机、聆听、思考、回答、指引、暂停/错误编排。图集见`apps/web/src/features/agent/assets/README.md`；它是角色美术，不包含校园事实或导航坐标。

姿态来自实际会话状态。轻微浮动、聆听环、思考点和指引提示使用CSS的变换/透明度；讲话条只是“正在朗读”指示，不是麦克风音量或音频采样。没有逐音素口型、骨骼绑定或Live2D模型，不冒充这些能力。

系统减少动态效果时停用动画，后台页面暂停装饰运动。角色使用一张298,724字节（约292KiB）的1536×1024透明WebP图集，异步解码、低优先级加载；图片失败时保留可操作的图标回退。无3D引擎、第三方角色运行时或新依赖。原地图、图块、楼层图字节不变。

## 字幕与语音边界

保留现有浏览器`SpeechRecognition`与`speechSynthesis`、学校文字问答API。用户说完一句后回答，再开始下一轮；不是全双工实时语音，也没有新接入云端ASR/TTS。云语音准备和尚未完成的适配工作见[47](47-companion-actions-and-voice.md)。

回答按句子分成短字幕，语音提供`onboundary.charIndex`时，字幕根据真实朗读位置推进；原回答仍完整朗读。没有该事件的浏览器保留首条可读字幕，完整回答可在抽屉查看，不用定时器假装同步。停止、打断、下一问题以及过期回调不能恢复旧字幕。

需要真实设备核实语音识别网络、麦克风权限、音色、边界事件和自动继续聆听。动画、单元测试或字幕变化不能证明识别/问答/朗读服务可用。

## 验证与部署

本地完整前端240项测试、TypeScript和Vite生产构建通过。主JS为487.87kB（gzip151.04kB），角色WebP为298.72kB；这些是构建产物大小，不是用户设备网络/帧率实测。GitHub结果以最终提交对应CI为准。Node交互测试不等于真实浏览器触控或视觉验收；当前环境的本地浏览器预览曾被策略阻止，本批未绕过该限制。

已部署`e555580`配套API的实例只需更新并重建web，沿用[30](30-interface-release.md)部署方式。无新增环境变量、依赖、API契约或数据库迁移。不执行生产部署、迁移、审核或发布；回退只需回到上一版web。

目标设备至少记录以下实际结果：

| 场景 | 应观察到的结果 |
| --- | --- |
| 首次打开、连接后刷新、收小 | 无常驻文字面板；不会自动申请麦克风 |
| 点击、慢拖、快拖、拖后松手、第二指触摸 | 只有真实点击启动操作，拖动不选中背后的地图 |
| 四个屏幕边缘、横竖屏、软键盘、页面缩放 | 角色/工具可找回，抽屉关闭按钮与输入框可触达 |
| 连续两轮语音、长回答、打断、后台恢复 | 状态与实际语音一致，旧字幕不串入下一轮 |
| 麦克风拒绝、识别网络失败、无语音支持 | 字幕说明原因，文字图标仍可进入交流 |
| 导航/楼层打开、视频播放、VR拦截 | 角色保留；视频暂停语音；核验后的VR入口可点击 |
| 键盘Tab/方向键/Escape、减少动态效果 | 可操作且焦点可见；减少动态时没有持续装饰动画 |
| 地图冷加载、角色图集失败、弱网 | 角色素材不阻塞地图；失败仍能操作 |

下一步优先记录这些真实验收结果，再处理云语音服务接入。不得用更多装饰掩盖延迟、断音或地图加载问题。
