# 质量、安全与验收

## 1. 基础版本必查

| 验证 | 目的 |
| --- | --- |
| Python静态检查、前端typecheck/build | 发现基础导入/类型/构建错误 |
| 公开查询过滤 | 草稿、内部、受限、撤回、停用校园均不泄露 |
| UUID/分页/搜索验证 | 边界输入正确报错，不被LIKE通配符放大 |
| DB不可用与迁移未完成 | readiness返回503，不能假装健康 |
| 生产配置 | 禁止SQLite、短/占位密码和通配Host |
| planned端点隔离 | 文档定义不会意外挂载为可调用功能 |
| 契约生成检查 | DTO、OpenAPI与前端类型同步 |
| PostgreSQL CI | 真实PostgreSQL迁移、种子幂等及数据库约束 |
| 容器CI冒烟 | 构建镜像、迁移顺序、Nginx同源转发、基础接口 |
| 桌面/手机视觉检查 | 无溢出、可读、可操作、错误和空状态真实 |

SQLite快速测试不能替代PostgreSQL验证；本地进程成功不能替代服务器部署。未运行的检查写“未运行”，不记为通过。

## 2. 功能阶段验收

### 地图与路线

至少核对三个已知地标的像素坐标和一个跨河/绕楼场景；多缩放级别点击区域不漂移。闭边后路线变化或不可达；旧图版本路线拒绝绘制；未校准数据不显示精确距离。楼层路网核对真实入口和跨层连接。

### 智能体

评测集至少包含：点位事实、校史来源、参观政策、资料缺失、同名消歧、连续追问、缩短行程、提示注入、越权材料请求、平台不可用、重复提交、取消/断线重连、旧上下文动作。

保存题目、预期依据、实际回答、模型/知识版本、错误类别与审核人；不只记录一个总正确率。政策与核心校史严重错误必须修正再发布。

### 权限

匿名直接访问受限资源ID、篡改role、读取他人session/turn/route、失效签名、撤回内容、跨站写请求、未审核文件直链均需覆盖。使用前端隐藏而后端200视为失败。

## 3. 访问与素材

- 平台密钥只在后端环境；staff身份只能来自可信认证。
- 对私有素材在读取时检查权限，不只在列表接口过滤。
- 私有原件不进Git、网页public目录、公开对象存储或公共缓存。
- 上传限制MIME/实际文件结构/大小/像素量；路径由服务端生成，拒绝穿越、可执行脚本和HTML伪装图。
- 图片需要脱敏与使用授权；不承诺阻止截图。水印和访问记录是补充措施。
- 外部全景只引用经过核实的官方URL；防止把用户给的内网URL作为抓取目标。

## 4. 内容治理

来源必须有发布者、版本、有效期和公开范围。讲解词及政策经过人审。用户提交的历史咨询先脱敏，不能直接入公开知识库。

检索文档中的指令不拥有系统权限；模型输出必须验证。普通意见与批评可以正常回应，避免无差别过滤。对不明确的问题先澄清；对无资料问题说明不足并转官方渠道。

知识库撤回传播可能延迟，因此业务层必须二次校验source有效状态，不能只依赖删除向量索引。严禁演示时用假来源编号装作有出处。

## 5. 日志与留存

默认记录request_id、方法、状态、耗时，不记录密钥、完整URL查询串、请求body或未经脱敏咨询。上线初始建议匿名会话/事件24小时，脱敏咨询30天、审计180天；这些是待部门确认的运营参数，不作为法律期限。

统计优先聚合；原始记录只有获授权人员可访问。设置定期清理任务并验证有效，不仅写一条隐私说明。后台导出也必须检查权限。

## 6. 服务预算

在记录设备、并发与网络条件的测试下观察：基础API延迟、地图首屏资源量、平台首响应/完整回答耗时、错误率与内存。未经过真实测量，不宣传“毫秒响应”“支持万人同时在线”。

初始文件限制：图像单文件<=30MiB且解码像素上限100MP；音频<=50MiB；PDF<=30MiB；zip不作为在线公开上传类型。后续通过受控CLI分批导入更大原件，保留hash与来源。HTTP上传开放时单独调整对应代理限制，不全站无限放开。

## 7. 真实试用

记录用户类别（公众/校友/研学/学生）、任务、是否完成、耗时、未解决事项、错误与满意度。比较传统查资料流程和导览流程时统一任务条件。展示实际数据和样本量，不从测试样例虚构业务成效。
